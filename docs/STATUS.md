# 项目状态

## 已完成

- ESP32-S3、AS7341、VL53L0X、SPI TFT 驱动与任务调度
- 白色补光、环境光扣除和 15–25 mm 距离门控
- Python 串口采集、质量检查、趋势分析和数据审计
- 六颗油桃的跨天数据整理与留一水果验证
- 逻辑回归整体模型与轻量随机森林局部异常模型
- Python 到 ESP32 C 参数导出与固件部署
- KEY0–KEY3 引导的 P1–P4 四位置测量流程
- 中文 TFT 结果与 DeepSeek 报告页面
- ESP32 通过 HTTPS 直接调用 DeepSeek
- 云任务栈、显示看门狗、来源显示和重复请求防抖修复

## 当前验证结果

- 固件能够离线输出本地 `fresh` / `risk` 结果。
- 联网时能够请求 DeepSeek，并返回结构化风险、摘要与建议。
- 同一轮测量只触发一次云请求，清除结果后才能开始下一轮。
- 训练采用留一完整水果验证，避免同一水果的数据泄漏到训练集与测试集两侧。
