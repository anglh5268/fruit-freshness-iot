# 端云协同架构

## 端侧数据流

1. AS7341 先关闭补光读取环境光，再打开白色补光读取总光谱。
2. 固件计算 `max(Lit - Ambient, 0)` 得到净反射通道。
3. VL53L0X 将有效采集限制在 15–25 mm。
4. 每个位置累计 20 帧，计算稳定的通道特征。
5. 用户围绕油桃采集 P1–P4 四个位置。
6. 逻辑回归判断整体趋势，浅层随机森林补充局部腐坏检测。
7. 四位置聚合后生成 `fresh` / `risk`、置信度、风险等级和局部异常标记。

## 云端数据流

ESP32 只在本地结果稳定且用户确认后调用 DeepSeek。请求包含水果类型、距离、四位置本地
结论和置信度。提示词要求模型：

- 不修改本地模型结论；
- 不虚构未测量的事实；
- 低置信度时建议重新测量；
- 返回限定长度的结构化 JSON；
- 只提供风险解释和处理建议。

返回字段包括：

```json
{
  "risk_level": "low | medium | high | unknown",
  "summary": "简短结果说明",
  "advice": "简短处理建议"
}
```

云端不可用时，本地结果仍保留在 TFT 上，设备不依赖大模型完成核心判断。
