# 物联网设计竞赛项目任务清单

## 最终目标

完成一台基于 ESP32-S3、AS7341、VL53L0X 和云端大模型的油桃表面新鲜度与
腐败风险筛查设备。ESP32 本地输出 `Fresh / Warning / Spoiled`，云端大模型
负责生成解释和处理建议。

## 三号位：光谱数据与边缘模型

### 已完成

- [x] Python 与 VS Code 工作区
- [x] 串口结构化数据解析与原始 CSV 保存
- [x] 距离、补光和反射有效性质量门控
- [x] 环境光扣除后的净反射数据流程
- [x] 重复性分析与先导光谱对比
- [x] 逻辑回归、随机森林和 RBF-SVM 比较
- [x] C 头文件导出及 ESP32 浮点推理一致性验证
- [x] 三类水果识别工程链路验证
- [x] 新鲜度元数据采集字段
- [x] 3 个油桃 Day 0、4 个位置、共 240 个正式帧
- [x] 自动选择重测文件的新鲜度数据整理程序

### 每天必须完成

- [ ] 对 NECT01～NECT03 重新称重并记录室温
- [ ] 按实际状态填写 fresh / warning / spoiled
- [ ] 记录硬度、表面现象和相同方向照片
- [ ] 对固定 P1～P4 各采集 20 个合格帧
- [ ] 运行 `analyze_freshness_dataset.py`
- [ ] 当天检查缺失位置、帧数和稳定性警告，必要时立即重测

### 数据出现变化后

- [ ] 出现 warning 后训练 fresh / warning 第一版模型
- [ ] 出现 spoiled 后训练三分类模型
- [ ] 使用留一完整水果验证，禁止同一水果泄漏到训练和测试两侧
- [ ] 比较原始光谱、Clear 归一化和稳健组合特征
- [ ] 生成混淆矩阵、准确率和各水果留出结果
- [ ] 导出新鲜度模型 C 头文件
- [ ] 验证 Python 与 ESP32 推理一致

## 优先级

1. 每日连续数据采集，不能事后补回。
2. 新鲜度分析程序、云端中转和 ESP32 Wi-Fi 并行推进。
3. 出现 warning 后立即训练第一版模型。
4. 三分类模型完成后替换 ESP32 模型并做端云联调。
5. 最后完成固定结构、界面、测试、报告和演示。
